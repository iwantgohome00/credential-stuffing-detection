# 크리덴셜 스터핑 탐지 미니 프로젝트

유통 기업 온라인몰을 가정하고, 가상 로그인 로그에서 **크리덴셜 스터핑(유출 자격증명 대입) 공격을 탐지**하는 규칙을 설계·구현·평가한 프로젝트입니다. 단순 규칙에서 시작해 오탐을 줄이고, 최신 회피 기법(저속 분산)까지 탐지하도록 단계적으로 개선했습니다.

> 모든 데이터는 **합성(가상) 로그**이며 실제 개인정보를 포함하지 않습니다. 탐지에는 정답 라벨(`label`)을 사용하지 않고, 평가 시에만 사용합니다.

## 실행 방법

```bash
# 1) 로그 생성 → 2) 탐지 → 3) 평가 순서로 실행
python3 01_generate_logs.py          # login_logs.csv 생성
python3 02_detect_v1.py              # 1차 규칙 탐지 → detections_v1.csv
python3 03_evaluate.py               # v1 평가

python3 04_detect_v2.py              # 위험 점수 방식 → detections_v2.csv
python3 03_evaluate.py detections_v2.csv

python3 05_generate_logs_rich.py     # 지역/ASN/시간 + 고객 오타 보강 로그
python3 06_detect_v3.py              # 정량+정성 통합 → detections_v3.csv
python3 03_evaluate.py detections_v3.csv

python3 07_generate_logs_trend.py    # 저속 분산(low-and-slow) 공격 추가 로그
python3 08_detect_v4.py              # IP/ASN/글로벌 3층 집계 → detections_v4.csv
python3 03_evaluate.py detections_v4.csv
```

Python 3 표준 라이브러리만 사용합니다(외부 패키지 불필요). CSV 파일은 스크립트 실행으로 재생성되므로 저장소에는 포함하지 않습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `01_generate_logs.py` | 기본 가상 로그인 로그 생성 |
| `02_detect_v1.py` | 1차 규칙 탐지(IP 기준 단순 규칙) |
| `03_evaluate.py` | 평가(탐지율·정밀도·오탐률, 시나리오별 현황) |
| `04_detect_v2.py` | v2: 위험 점수 합산 + 정상 패턴 감점 |
| `05_generate_logs_rich.py` | 지역/ASN/시간, 고객 오타, stealth 공격 추가 로그 |
| `06_detect_v3.py` | v3: 정량 + 정성 신호 통합 |
| `07_generate_logs_trend.py` | 저속 분산(low-and-slow) 공격 추가 로그 |
| `08_detect_v4.py` | v4: IP / ASN·서브넷 / 글로벌 3층 집계 |

## 버전별 결과

| 버전 | 핵심 개선 | IP 단위 탐지율 | IP 단위 오탐 | 비고 |
|---|---|---|---|---|
| v1 | IP 기준 단순 규칙(OR) | 88.7% (47/53) | 2개 | 계정 탈취 19/28, 초기 데이터셋 2,788건 |
| v2 | 위험 점수 + 정상 감점 | 100% (53/53) | 0개 | 계정 탈취 28/28, 초기 데이터셋 2,788건 |
| v3 | 정량+정성 통합 | 100% (63/63) | 1개 | stealth 10/10, 확장 데이터셋 2,885건 |
| v4 | IP/ASN/글로벌 3층 집계 | 100% (153/153) | 1개 | low_slow 90/90, 최종 데이터셋 3,019건 |

- **v1 → v2:** "연속 실패" 규칙이 성공 한 번에 초기화되어 계정 탈취 공격을 놓치던 문제를, 실패율·없는 계정 비율 기반 점수로 개선.
- **v3:** ASN(데이터센터 여부)·국가·접속 시간대를 점수에 추가. 정량만으로는 놓치는 stealth 공격(유효 계정 2개만 시도)을 정성 신호로 탐지.
- **v4:** IP당 1~2회만 흩뿌리는 저속 분산 공격은 IP 기준(1층)으로는 90개 중 21개만 탐지. ASN·서브넷 집계(2층)로 90/90 탐지, 플랫폼 전체 베이스라인(3층)으로 공격 진행 자체를 경보.

> 탐지율 100%는 **공격 특징을 직접 설계한 합성 데이터**에서 나온 값으로, 규칙과 데이터를 함께 만든 데 따른 과적합이 포함됩니다. 실제 환경 성능을 보장하지 않습니다.

## 한계와 실무 보완점

- **합성 데이터 한계:** 실제 로그로 임계값 재튜닝 필요. 100%는 신뢰 대상 아님.
- **잔존 오탐:** 국내 거주망에서 오타가 잦은 정상 고객은 규칙만으로 거르기 어려움 → 분석가 검토 단계 필요.
- **주거용 프록시:** 공격 IP가 정상 ISP에 섞이면 ASN 집계로도 구분 불가 → 계정 단위 집계, 디바이스 핑거프린트, 행동 분석 필요.
- **근본 방어 병행:** MFA(2단계 인증), 유출 자격증명 대조, 비밀번호 재사용 차단, CAPTCHA/레이트 리밋.
